## Manifesto

Yerel donanımda çalışan yapay zekâ araçları daha anlaşılır, denetlenebilir ve ulaşılabilir olmalı.

Buradaki projeler Termux, Hermes Agent ve açık kaynak araçlarla kendi çalışma düzenini kurmak isteyenler için. Türkçe rehberler, sürüm notları ve varsayılanı Türkçe olan forklar üretiyorum. Amaç gösterişli otomasyon değil, gerçekten kullanılabilen sistemler.
